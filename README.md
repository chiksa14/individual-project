📱 О проекте
QuranFlow Academy — это полнофункциональное Telegram Mini App, созданное для онлайн-школ арабского языка и Корана. Приложение сочетает в себе образовательную платформу, ежедневный помощник для мусульман и интерактивный тренажёр для изучения арабского.

✅ Упростить доступ к исламскому образованию через Telegram

✅ Автоматизировать процесс записи на курсы

Установка для пользователей

Начните использовать все функции приложения

Установка для разработчиков
bash
# 1. Клонируйте репозиторий
git clone https://github.com/ваш-логин/quranflow-academy.git

# 2. Перейдите в папку проекта
cd quranflow-academy

# 3. Запустите локальный сервер (варианты)
# Python
python -m http.server 8000

# Node.js с serve
npx serve .

# PHP
php -S localhost:8000

# 4. Откройте в браузере
open http://localhost:8000
